BMW M4 Competition M Package by SRT Performance.

- Original: https://sketchfab.com/3d-models/bmw-m4-competition-m-package-5c0a2dafb1ad408d9fc9eeef9aee531b
- Author: https://sketchfab.com/TheRealSRT

- Downloaded derivative: https://github.com/lukaizj/car-mod-saas/blob/main/public/models/bmw-m4.web.glb
- Derivative SHA-256: 1a072ff0aee180b1c13d60c0ae47c93e7c151240c532b60101449a651531b3e1

The upstream web derivative uses Meshopt geometry compression, WebP textures
limited to 512 px, and removes hidden interior meshes and unused textures.
This project normalizes scale, changes runtime paint/glass/metal materials and
adds fictional plates. No affiliation or endorsement is implied.

The model is a BMW coupe, not an exact Toyota Camry replica of the concept image.
