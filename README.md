# Песочница: 3D-демо автомойки

Изолированная копия интерактивного демо «Автомойка» с лендинга ornode.org.
Здесь лежит ровно то, что нужно, чтобы дорабатывать 3D-сцену и модальное окно,
и ничего больше. Остальной сайт в песочницу не входит.

## Запуск

Нужны Node 22+ и pnpm 10.

```bash
pnpm install
pnpm dev        # http://localhost:3005 — кнопка «Открыть демо автомойки»
pnpm check      # typecheck + тесты + проверка замороженной зоны (перед сдачей)
```

## Что здесь есть

«3D-модель» — это не файл, а процедурная сцена на three.js: здание, боксы,
оборудование и работник собираются кодом. Единственный внешний ассет — машина
`public/models/carwash/vehicle.glb` (CC BY 4.0, см. `ATTRIBUTION.md` рядом) и
текстуры бетона (CC0).

### Редактируемая зона (ваши файлы — возвращаются в основной сайт)

| Что | Где |
|---|---|
| Модальное окно демо, правая панель | `src/components/CarWashDemo.tsx` |
| Сцена three.js: камера, свет, тур, оверлеи | `src/components/CarWashScene.tsx` |
| Геометрия автомойки, набор примитивов, работник, машина | `src/components/carwash/*.ts` |
| Раскладка боксов, цикл тура, сценарии, тайминги | `src/lib/carwash-layout.ts`, `carwash-loop.ts`, `carwash-presentation.ts`, `carwash-simulation.ts` |
| Ассеты | `public/models/carwash/*` |
| Стили автомойки | блок `РЕДАКТИРУЕМО` в конце `src/app/globals.css` (классы `carwash-*`) |
| Тексты окна | `src/i18n/messages/ru.json` → `home.industries.carwashDemo` |
| Тесты | `test/carwash-*.test.ts(x)` — держите зелёными, новые приветствуются |

Новые файлы кладите в `src/components/carwash/` или рядом с `carwash-*` в `src/lib/`.
Новые CSS-классы — с префиксом `carwash-`, внутри блока `РЕДАКТИРУЕМО`.

### Замороженная зона (только для запуска — не менять)

Эти файлы в основном сайте общие для шести отраслевых демо и всего кабинета.
Правки в них приняты не будут; `pnpm check:frozen` сверяет их с манифестом
`frozen.sha256`.

- `src/components/industry/DemoPanelUi.tsx` — общая рамка панели демо.
- `src/components/ui/*` — shadcn-примитивы (button, card, popover, select).
- `src/lib/utils.ts`, `src/lib/industry-demo.ts`.
- `src/app/globals.css` до маркера `РЕДАКТИРУЕМО`: канон темы, токены, блок `farm-*`.
- `src/components/SandboxPage.tsx`, `src/app/layout.tsx`, `src/app/page.tsx` — обвязка песочницы.
- Конфиги: `package.json`, `tsconfig.json`, `next.config.ts`, `vitest.config.ts`, `postcss.config.mjs`.

Нужен новый пакет или правка в замороженном файле — напишите, обсудим отдельно.

## Правила дизайна (обязательны)

- Цвета, тени, радиусы — только через CSS-токены из `globals.css` (`var(--color-…)`,
  `var(--radius-…)`, `var(--shadow-…)`). Хардкод hex/px-теней запрещён.
- Один акцентный цвет — циан `--primary`; нейтрали тёплые (stone).
- Bold запрещён везде: максимум `font-weight: 400`.
- Кнопки — pill (`rounded-full`), компоненты — из `src/components/ui`.
- Инструктивных абзацев и подзаголовков-пояснений в UI не пишем.
- Шрифты: Inter (текст), Inter Tight (заголовки) — уже подключены в layout.
- Адаптив: окно работает от 360 px; проверяйте брейкпоинты 68rem / 50rem / 35rem.
- `prefers-reduced-motion` уважаем: анимации отключаются (см. существующие правила).

## Как работать и сдавать

1. Сделайте fork этого репозитория (кнопка Fork на GitHub) и клонируйте свой fork.
2. Работайте в отдельной ветке, коммиты небольшие, сообщения по делу:
   `feat: новая крыша над боксами`, `fix: тень машины на мокром полу`.
3. Перед сдачей `pnpm check` должен быть зелёным: типы, тесты, замороженная зона.
4. Откройте Pull Request в этот репозиторий. В описании: что изменено и зачем,
   отдельно отметьте, если менялись тайминги тура (`carwash-loop.ts`) или
   раскладка боксов (`carwash-layout.ts`).
5. Скриншот или короткое видео результата в PR очень помогут.

С нашей стороны редактируемые файлы копируются в основной сайт как есть,
поэтому важно не менять их расположение, имена файлов и пути импортов.
